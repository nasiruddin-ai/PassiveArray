# Squareko Tools

A collection of small web tools. Each tool folder works on its own on your PC
(double-click its `Start.bat`), and this root folder also deploys all of them
together as one website on Netlify.

## The tools

| Folder | What it is | On Netlify? |
|---|---|---|
| `domain-finder/` | Finds domain names that are free to buy | Yes, at `/domain-finder/` |
| `domain-age-checker/` | Shows when a domain was registered | Yes, at `/domain-age-checker/` |
| `plagiarism-checker/` | Checks text against the web or compares two texts | Yes, at `/plagiarism-checker/` |
| `jpg-to-pdf/` | Converts images to a PDF in the browser | Yes, at `/jpg-to-pdf/` |
| `seo-roi-calculator/` | Estimates SEO return on investment | Yes, at `/seo-roi-calculator/` |
| `creator-tools/` | 35 creator tools for YouTube, Instagram, TikTok, Twitch and X (see its README) | Yes, at `/creator-tools/` |
| `video-downloader/` | Downloads videos with yt-dlp | **No.** It needs the yt-dlp and ffmpeg programs and long downloads. Netlify cannot run those. Use a small VPS, Railway or Render for it. |
| `social-scheduler/` | An n8n workflow, not a web page | No. It runs inside n8n. |

## How the Netlify site is put together

```
Squareko/
  netlify.toml            Netlify settings (build command, publish folder, functions)
  build.js                Copies each tool page into dist/  (run by Netlify, or: node build.js)
  home.html               The home page listing the tools -> becomes dist/index.html
  netlify/functions/      The /api routes for the tools that need a backend
    domain-finder-check.mjs   -> /domain-finder/api/check
    domain-age.mjs            -> /domain-age-checker/api/age
    plagiarism.mjs            -> /plagiarism-checker/api/status, compare, check, fetch-url
    creator-youtube.mjs       -> /creator-tools/api/youtube
    creator-twitch.mjs        -> /creator-tools/api/twitch
    creator-ai.mjs            -> /creator-tools/api/ai (optional Claude upgrade)
  <tool>/lib/             Shared logic, used by both the local server.js and the function
  dist/                   Generated by build.js. Do not edit; it is rebuilt every deploy.
```

Netlify serves the pages in `dist/` as static files and runs the functions on
demand, so there is no server to keep running. The free plan is enough.

## Deploying to Netlify

Drag and drop in the Netlify website does **not** work for this folder, because
it does not package the functions. Use one of these instead.

### Option A: command line (recommended)

Once, on your PC:

```
npm install -g netlify-cli
netlify login
```

Then, in this root folder (the one with `netlify.toml`):

```
netlify deploy --prod
```

The first time it asks "Create & configure a new project?" Say yes, pick your
team, and give it a name such as `squareko-tools`. Every later
`netlify deploy --prod` from this folder updates the same site.

### Option B: GitHub

1. Put this whole folder in a GitHub repository.
2. On Netlify: **Add new project > Import an existing project > GitHub** and pick it.
3. Leave the settings as they are; `netlify.toml` already holds them. Click **Deploy**.
4. Every push to the main branch redeploys.

### Testing the Netlify version on your own PC

```
netlify dev
```

Then open `http://localhost:8888`. This runs the build and the functions
exactly as Netlify does.

## Plagiarism checker on Netlify: the Google key

Locally the key lives in `plagiarism-checker/config.json`. On Netlify, set it
as environment variables instead so it never sits in a file:

1. Netlify: open the project, then **Project configuration > Environment variables**.
2. Add `GOOGLE_API_KEY` and `GOOGLE_CX` with the values from the plagiarism
   checker README. Optional: `MAX_QUERIES_PER_CHECK` (default 20 on Netlify).
3. Redeploy. The page stops showing the "not set up" notice.

## Creator Tools keys on Netlify

The YouTube and Twitch tools in `creator-tools/` need free API keys. Add
`YOUTUBE_API_KEY`, `TWITCH_CLIENT_ID` and `TWITCH_CLIENT_SECRET` under
**Project configuration > Environment variables** and redeploy. The step-by-step
is in `creator-tools/README.md`. Optional: `ANTHROPIC_API_KEY` upgrades the four
generator tools to AI-written output; without it they use built-in templates.

## Things to know about the hosted version

- A Netlify Function must answer within 10 seconds. The domain tools therefore
  wait at most 4 seconds per registry lookup, and the plagiarism web check
  looks at 20 sentences per run instead of 40. Results say so when something
  was cut short.
- The free plan includes 125,000 function calls a month.
- The domain finder talks to WHOIS servers on port 43 for endings such as
  `.io` and `.co`. If those show "Could not check" after deploying, tell me.

## Adding a new tool to the site

1. Create the tool folder with its `index.html` (and `server.js` for local use).
2. Add the folder to the `TOOLS` list in `build.js`.
3. Add a card to `home.html`.
4. If it needs a backend, put the logic in `<tool>/lib/`, add a function in
   `netlify/functions/`, and list the lib folder under `included_files` in
   `netlify.toml`. In the page, call the API with a relative path
   (`api/thing`, not `/api/thing`) so it works both locally and on the site.
